to run Frontend (NextJs) : npm run dev 

to run Backend (FastAPI/Python): python -m uvicorn main:app --reload --port 8000

Installing Mistral model is needed "mistral-7b-instruct-v0.2.Q4_K_M.gguf" , and should be put in "backend/mistral_model"

this is the link for the download : https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.2-GGUF , make sure to choose the Q4_K_M (4.37 Gb) version
